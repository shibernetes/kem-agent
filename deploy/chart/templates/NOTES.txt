WARNING: the checkpoint uses a file store while persistence is disabled. The
root filesystem is read-only, so unless extraVolumeMounts puts a volume at
config.checkpoint.store.path, the agent cannot save the checkpoint and every

To keep it across restarts, set persistence.enabled=true, which mounts a volume
at {{ .Values.persistence.mountPath }}, and set config.checkpoint.store.path to
