{{- else if eq (toString (dig "checkpoint" "store" "type" "" .Values.config)) "file" }}

WARNING: The checkpoint uses a file store, but persistence is off.

The root filesystem is read-only, so the agent can't save the checkpoint
unless config.checkpoint.store.path is set to a path on a volume mounted
with extraVolumeMounts. Without a saved checkpoint, every start replays all
retained events.

To keep the checkpoint across restarts, set persistence.enabled=true and set
config.checkpoint.store.path to a path under {{ .Values.persistence.mountPath }}.
